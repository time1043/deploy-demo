# Application Type

## SPA (Browser-only Rendering)

### Characteristics

- Static assets only
- Runs entirely in browser
- No server runtime required

### Examples

- `react-spa`
- `vue-spa`
- `angular-spa`

## Backend Server (Long-running server)

### Characteristics

- Persistent server process
- Port listening
- Stateful connections possible

### Examples

- `express`
- `fastify`
- `nest-v11-cmj` (NodeJS Runtime)
- `spring` (JVM Runtion)

## Fullstack Framework (SSR / Hybrid Rendering)

### Supported Runtime Targets

- Node Runtime

1. Traditional server runtime
2. Full Node.js APIs

- Serverless Runtime: Edge Runtime, Regional Functions

- Serverless Runtime

1. Function-based execution
2. Auto scaling

- Edge Runtime

1. Distributed edge execution
2. Low latency globally
3. Limited runtime APIs

### Examples

- `next`
- `tanstack-start` (nitro)
- `remix`
- `nuxt`
